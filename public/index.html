给开发团队的现代文档平台

MVP 版本，采用 Node.js 原生 HTTP 服务构建，风格参考 documentdb.io 的深色渐变与卡片布局。

快速部署命令
git clone <your-repo-url> cd website npm install npm run dev
# 打开浏览器 http://localhost:3000

极速启动

零框架负担，安装依赖后即可本地运行。

可扩展结构

后续可无缝增加 API、认证、数据库与搜索。

部署友好
