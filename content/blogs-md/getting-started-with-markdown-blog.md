## Why Markdown

You can now publish blogs in Markdown directly on your own site.

## Workflow

1. Add a `.md` file under `content/blogs-md/`.
2. Add front matter metadata.
3. Open `/blogs` and the post appears automatically.

## Benefits

- No third-party redirects
- Git-based version control
- Fast publishing workflow
